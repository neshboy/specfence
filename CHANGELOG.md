# Changelog

All notable changes to this project are documented here. Format loosely
follows [Keep a Changelog](https://keepachangelog.com/en/1.0.0/); versions
follow [Semantic Versioning](https://semver.org/).

Per-package release changelogs (generated by
[Changesets](https://github.com/changesets/changesets) once versioned
releases start shipping) will live at `packages/cli/CHANGELOG.md` and
`packages/action/CHANGELOG.md`. This top-level file tracks the project as a
whole.

## [Unreleased]

### Added
- Initial release: `@specfence/core` (manifest schema + deterministic
  glob-diff gate engine), the `specfence` CLI (`init`, `check`), and the
  `SpecFence` GitHub Action.
- Base-ref-pinned scope manifest (`.specfence/scope.yaml`, schema
  `version: 1`) with `ignore` / `deny` / `scopes[].globs`+`exclude`.
- Rename decomposition (old + new path both checked independently),
  symlink/submodule always-flagged detection, fail-closed handling for
  missing/malformed/oversized inputs.
- GitHub Action built on `pull_request` (never `pull_request_target`),
  REST-API-only (no `actions/checkout`), read-only permissions.
- This repository dogfoods itself: `.specfence/scope.yaml` +
  `.github/workflows/specfence.yml` + `.github/CODEOWNERS`.
